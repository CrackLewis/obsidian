
提供一套基于流（stream）的输入输出函数。

## 按字典序

F：
- `fprintf`
- `fscanf`

P：
- `printf`

S：
- `scanf`
- `sprintf`
- `sscanf`

V：
- `vfscanf`

## 按功能

### 格式化输入输出

格式化输入：

| 函数签名                                                | 功能                                 |
| --------------------------------------------------- | ---------------------------------- |
| `int scanf(const char *fmt, ...)`                   | 从标准输入根据格式串`fmt`读取一系列变量，返回成功读取的变量个数 |
| `int fscanf(FILE *file, const char *fmt, ...)`      | 从文件流根据格式串读取一系列变量，返回同上              |
| `int sscanf(const char *buf, const char *fmt, ...)` | 从字节序列根据格式串读取一系列变量，返回同上             |

格式化输出：

| 函数签名                                           | 功能                             |
| ---------------------------------------------- | ------------------------------ |
| `int printf(const char *fmt, ...)`             | 向标准输出根据格式串构造字节序列并输出，返回成功输出的变量数 |
| `int fprintf(const char *fmt, ...)`            | 向文件流构造并输出字节序列，返回同上             |
| `int sprintf(char *buf, const char *fmt, ...)` | 向缓冲区构造并输出字节序列，返回同上             |
